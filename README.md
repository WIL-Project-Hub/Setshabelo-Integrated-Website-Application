# setshabelo_integrated_asap.net_website_application

A web-based platform developed by Secret Design for Setshabelo Primary School in Welkom, Free State. 

We will be using ASP.NET Core MVC (C# / .NET) as our frontend and backend utilizing Supabase as the database.

Main Functions of The Website:
* Overall Website For The school showcasing school information & achievements.
* Online Registration System.
* Registration Tracker.
* General Announcement/Update Feature from the school to parents.
